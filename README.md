# Maquette de l'IHM — générateur de paroles

La maquette des quatre écrans de l'interface du générateur de paroles :
le brief, le plan de rimes, l'écriture en direct, le texte annoté.

À lire en ligne : https://samy83.github.io/maquette-ihm-lyrics/

Une maquette, pas l'outil : les boutons ne font rien. Les mots, les comptes
de syllabes, les refus et les coûts affichés viennent d'un vrai son écrit
par le générateur.
